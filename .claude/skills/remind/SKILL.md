# /remind — напоминания о записи на завтра

Обёртка над `./project/manager/remind/`. Выполни:
```bash
cd project/manager/remind
npm run start
```

Поведение (уже реализовано):
- Берёт из `Booking` все записи на завтра со статусом `CONFIRMED` и `remindedAt = null`.
- Каждой записи с известным `telegramChatId` — отправляет напоминание в Telegram и ставит `remindedAt = now()` (повторный запуск в тот же день дубликат не пришлёт).
- Записи без `telegramChatId` (сделаны через сайт `/book`, не через бота) — пропускаются с понятной причиной, скрипт не падает.
- Сбой отправки одной записи (Telegram недоступен и т.п.) — попадает в «ошибки» отчёта, остальные записи всё равно обрабатываются.
- В конце — отчёт: сколько отправлено / пропущено / ошибок.

Ключи и адреса — только из `./project/bot_administrator/.env` (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_API_BASE`) и `./project/.env` (`DATABASE_URL`) — не хардкожены.

Не переписывай логику заново — она уже реализована и протестирована (`src/remind.ts`). План и границы (что сделано сегодня, что отложено) — в `./project/manager/PLAN.md`.
