# Напоминания клиентам о завтрашней записи

Ничего не кладёшь на вход — читает записи (`Booking`) прямо из БД.

## Вход

Записи в таблице `Booking` со статусом `CONFIRMED`, у которых `startAt` — завтра. Отправляются только те, у кого известен `telegramChatId` (клиент писал боту напрямую, не через сайт `/book`).

## Команда

```
/remind
```

Без скилла — то же самое руками:
```
cd project/manager/remind
npm run start
```

## Выход

Сообщение в Telegram каждому, кому напоминаем, плюс отчёт в консоли:
```
Напоминания на 16.09.2026 (записей на завтра: 2)

✅ Отправлено: Мария Иванова, 15:00, Маникюр у Анна (chat 733067375)
⏭️  Пропущено (нет Telegram-чата — запись с сайта): Ольга Кузнецова, 17:30, ...

Итог: 1 отправлено, 1 пропущено, 0 ошибок
```
Файлов не создаёт. Отправленным записям ставится `remindedAt` — повторный запуск в тот же день дубликат не пришлёт.

## Ключи

`./bot_administrator/.env`: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_API_BASE`. `./.env`: `DATABASE_URL`.

## Что не делает (см. `../PLAN.md`)

Напоминания для записей с сайта, автозапуск по расписанию, настраиваемое окно (жёстко «за день»).
