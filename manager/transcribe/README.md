# Расшифровка и осмысление записей

Кладёшь аудио/видео — получаешь расшифровку + саммари + таблицу задач одним `.md`-файлом.

## Вход

Аудио/видео файл (mp3, wav, m4a, ogg, oga, flac, aac, wma, mp4, mov, avi, mkv, webm).

## Команда

```
/transcribe
```
— без аргументов: берёт всё из `recordings/`, успешно обработанные исходники уезжают в `to_delete/`.

```
/transcribe ~/Downloads/zoom.m4a "путь/со пробелами.mp4"
```
— конкретные файлы (можно вне проекта); исходники не трогает.

Без скилла — то же самое руками:
```
cd project/manager/transcribe
npm run start [-- "путь1" "путь2"]
```

## Выход

Один `.md` на файл в `ready/`: расшифровка → саммари (5–7 пунктов) → таблица задач (`Задача | Ответственный | Срок | Основание — цитата`). Имя = имя исходника + дата-префикс `ГГГГ-ММ-ДД_`, если дату удалось определить.

`stats.json` в этой папке — сколько ждёт в `recordings/`, сколько готово в `ready/`, когда последний раз запускался (без содержимого и персданных).

## Ключи

`./bot_administrator/.env`: `ASSEMBLYAI_API_KEY`, `ASSEMBLYAI_BASE_URL`, `OPENROUTER_API_KEY`, `OPENROUTER_BASE_URL`.
